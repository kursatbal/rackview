Welcome to RackView

Quick tour of what you can do here.

🧰 Tools menu

The Tools ▾ button in the top bar groups every live-pull/integration screen in one place: LLDP Discovery, LLDP Auto-Cabling, SAN Switch Mapping, Storage Mapping, ESXi NIC Verification, iDRAC / iLO, Firmware Status, Firmware List, and Activity Log. See the cards below for what each one does.

✏️ Edit mode

Click Edit in the top bar to drag devices into new U positions, rename/delete them, or edit their fields (IP, serial, notes…) in the side panel.

🔌 Show cabling

Right-click a device → "Show cabling" to see only its connections. Or use the Cabling menu for "Create cabling" (click port → port to draw a new cable).

🏷️ Renaming & labels

Right-click a port to give it a custom display name. Right-click a device's name (left side) to rename it, or drag that label / a port group label somewhere less cluttered.

✂️ Cable actions

Right-click a cable to jump to the device on the other end, or delete it. Hover any cable for a quick tooltip.

🔍 Search & Impact

Search (or Ctrl+K) finds devices by IP, MAC, serial, port, VLAN. Click a device → Impact tab to see what breaks if it goes down.

📡 LLDP & Export

LLDP Discovery saves what LLDP sees as an info note on each port — never touches cabling. LLDP Auto-Cabling is the separate tool that actually creates/updates cables from LLDP. Export cables downloads the rack's cabling as an Excel file.

🔗 SAN Switch Mapping

Pick a SAN switch already placed in a rack, enter its IP and login, and pull its live port and zoning info over SSH (Brocade FOS or Cisco MDS). The username/password are used once and never saved — only the IP and the switch's own reported state are kept.

🗄️ Storage Mapping

Same idea for storage arrays — pull live FC port status and WWNs from a Dell PowerVault/ME array over SSH. Each port also shows where it's cabled to, cross-referenced against RackView's own cabling. Credentials are used once and never saved.

🖥️ ESXi NIC Verification

Pulls physical NIC link status and vSwitch mapping from an ESXi host over the vSphere API (no SSH needed). Matched against the device's vmnic_map to show where each recorded cable actually goes. Also supports pulling every host from a vCenter in one go, matched to rack devices by mgmt IP. Credentials are used once and never saved.

🔧 iDRAC / iLO

Pulls BIOS/BMC firmware version and health (PSUs, fans) from a Dell iDRAC or HPE iLO over Redfish (HTTPS) — the out-of-band management controller, separate from the ESXi NIC Verification pull. Credentials are used once and never saved.

🧾 Firmware Status

Groups every deployed device by vendor/model and shows what firmware is actually running (from the latest live pull, where available) next to a hand-entered "latest known" version — flags a model as Outdated when they don't match. RackView has no internet access, so "latest known" has to be typed in by hand and kept up to date.

📚 Firmware List

The full catalog reference lookup — every firmware-bearing model RackView knows about, whether or not anyone has one in a rack yet, so you can check "what's current for the ME5024" without needing one deployed. Editable from here too; edits update the same table Firmware Status compares against.

📜 Activity Log

Every device and cable create/update/delete is recorded with a timestamp and a before/after diff — no login system, so it tracks what changed, not who changed it.

📋 Devices

A flat, sortable/filterable table of every device across every rack — name, category, mgmt IP, firmware/version (pulled live where available, from SAN/Storage/ESXi mapping), serial, owner. Click a row to jump straight to that device in its rack.
